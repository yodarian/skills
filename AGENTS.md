# AGENTS

This repository is configured for the engineering skills with a local markdown-based issue tracker, the default triage label vocabulary, and a single-context domain documentation layout.

## Agent skills

### Issue tracker

This repository uses local markdown files under .scratch for work items and specs. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

This repository uses the default canonical triage labels: needs-triage, needs-info, ready-for-agent, ready-for-human, and wontfix. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

This repository uses a single-context layout with a root CONTEXT.md and a docs/adr directory. See [docs/agents/domain.md](docs/agents/domain.md).
